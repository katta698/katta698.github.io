What the vendors do and don’t tell you

The three publish very different amounts, and that difference is itself worth knowing when you decide how far to trust a status page.

CloudIncident startUpdate history Affected servicesRegions
AWSNot published separatelyYes Coarse (“Multiple services”)Yes

Google CloudYesYes, timestamped Yes, itemisedYes, itemised
Why the timings below are Google’s only. Google publishes when an incident began and, separately, when it first said something publicly, so the gap between the two is a real number. AWS’s status data carries no start time distinct from its first announcement, making that gap structurally zero; Azure’s feed carries no start time at all. Ranking all three would put AWS first for disclosing less, so only the cloud that supplies the inputs is measured.
