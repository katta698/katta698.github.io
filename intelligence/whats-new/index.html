What's new

Every announcement from all three clouds

1,365 announcements from AWS, Azure and Google Cloud, filterable by service and date. Each one links to the vendor's own page — nothing here is summarised or rewritten.

Built from the three clouds' own release feeds, not from a summary of them. Coverage begins 2026-08-25 for AWS, 2025-09-27 for Azure and 2026-08-05 for Google Cloud — anything earlier was already off the vendors' feeds before this archive existed. Blog posts and CVE bulletins are collected too but deliberately kept out of this view: they answer a different question. Service labels come from each vendor's own naming, so a few will be imprecise; the link is always the authority.
