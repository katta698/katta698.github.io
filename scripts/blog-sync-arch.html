Blog Sync Architecture

How a Blogger post becomes live at jayanthkatta.com/blog/

How it works — step by step

#StepWhere
1Write and publish post on Blogger editorblog.jayanthkatta.com
2sync_blog.py fetches all posts via Blogger JSON feedscripts/sync_blog.py
3Script cleans HTML (removes ChatGPT junk) and rebuilds all blog/ pagesLocal / GitHub Runner
4git commit + push sends updated blog/ to GitHubTerminal
5GitHub Pages auto-deploys in ~1-2 minutesgithub.com
6Post is live at jayanthkatta.com/blog/Live site

Two ways to trigger sync

TriggerWhenAction needed
ManualRight after publishing, want it live nowRun commands below + git push
Nightly Auto1 AM UTC / 6:30 AM IST every dayNothing — GitHub Action handles it

Manual sync commands

cd C:\Projects\Engineering\katta698.github.io
python scripts/sync_blog.py
git add blog/
git commit -m "Sync blog — new post: your title here"
git push
